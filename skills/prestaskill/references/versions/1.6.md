# PrestaShop 1.6

Tout ce qui est marqué *(à vérifier)* : grep dans le core ou WebFetch la doc avant de l'utiliser.

PHP 5.2 → 7.1 (voir php.md) · Symfony : aucun · Thème défaut : default-bootstrap · Thèmes enfants : non · BO : Smarty (Helpers) · Traductions : `$this->l()` · Doc : https://doc.prestashop.com/display/PS16/Developer+Guide

- Pas de Symfony, pas de Twig, pas de composer obligatoire. Tout est legacy : `ObjectModel`, `ModuleAdminController`, `HelperForm`, `HelperList`.
- Pas de thème enfant : on modifie une **copie** du thème. Surcharge de tpl de module : `themes/<theme>/modules/<module>/<fichier>.tpl`.
- Assets : `$this->context->controller->addCSS()` / `addJS()` dans `hookHeader` / `hookDisplayHeader`.
- Debug local : `_PS_MODE_DEV_` à `true` dans `config/defines.inc.php`. Jamais en production.
- Cache : supprimer `cache/class_index.php`, vider `cache/smarty/compile/` et `cache/smarty/cache/`.
