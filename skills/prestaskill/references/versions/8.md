# PrestaShop 8

Tout ce qui est marqué *(à vérifier)* : grep dans le core ou WebFetch la doc avant de l'utiliser.

PHP 7.2 → 8.1 (8.1 recommandé) · Symfony 4.4 · Thème défaut : classic · Thèmes enfants : oui · BO : Smarty + Twig (plus de pages migrées) · Traductions : `trans()` · Doc : https://devdocs.prestashop-project.org/8/

- Symfony 4.4, PHP 7.2 → 8.1. Beaucoup de code déprécié en 1.7 est supprimé : avant de réutiliser un vieux snippet, grep la méthode dans le core.
- Overrides toujours supportés mais **découragés** ; modules publiés sur Addons : overrides fortement déconseillés.
- Services du module (depuis 1.7.6) : `config/services.yml` → conteneur Symfony seulement ; `config/admin/services.yml` → BO (legacy + Symfony) ; `config/front/services.yml` → front legacy (+ Symfony).
- **Fiche produit BO** : à partir de 8.1, deux pages produit coexistent, choisies par le feature flag `product_page_v2` (BO > Paramètres avancés, page des nouvelles fonctionnalités ; actif par défaut sur une installation neuve de 8.1, une boutique migrée peut être restée sur l'ancienne). Demander laquelle est active.
  - Nouvelle page : champs ajoutés par `actionProductFormBuilderModifier`, enregistrés par `actionAfterUpdateProductFormHandler` / `actionAfterCreateProductFormHandler`. `displayAdminProductsExtra` reste supporté (onglet ajouté) mais déconseillé pour un nouveau module.
  - Ancienne page (8.0, ou flag désactivé) : `displayAdminProductsExtra`, `displayAdminProductsMainStep…`.
- Fiches commande et client BO : pages Symfony (depuis 1.7.7 / 1.7.6), hooks dans 1.7.md (`displayAdminOrderMain`, `displayAdminOrderSide`, `displayAdminOrderTabLink` / `TabContent` ; `displayAdminCustomers`, `actionCustomerFormBuilderModifier`). Les hooks de l'ancienne page commande (`displayAdminOrderLeft` / `Right`…) ne sont plus appelés *(à vérifier)*.
- Debug local : `_PS_MODE_DEV_` à `true` dans `config/defines.inc.php` (ou BO > Paramètres avancés > Performances > Mode debug) → erreurs PHP et barre de debug Symfony dans le BO. Jamais en production.
- Cache : `php bin/console cache:clear` ou `rm -rf var/cache/*`.

Module multi-versions : voir modules.md § Module compatible multi-versions.
