# PrestaShop 9

Tout ce qui est marqué *(à vérifier)* : grep dans le core ou WebFetch la doc avant de l'utiliser.

PHP 8.1 → 8.4 (9.0), → 8.5 (9.1) · Symfony 6.4 · Thème défaut : hummingbird à partir de 9.1 (devdocs ; 9.0 : vérifier le thème installé) · Thèmes enfants : oui · BO : majorité Twig/Symfony · Traductions : `trans()` · Doc : https://devdocs.prestashop-project.org/9/

- Symfony 6.4, PHP 8.1+. Nouvelle API admin (OAuth2). Hummingbird (Bootstrap 5.3, webpack, Node 20) est le thème par défaut à partir de 9.1.
- Beaucoup de pages BO restantes migrées en Symfony : les hooks legacy de ces pages peuvent ne plus être appelés → grep le hook dans le core avant de s'y fier.
- Attention aux APIs Symfony supprimées entre 4.4 et 6.4 (ex : `Symfony\Component\HttpFoundation\Session` usage, `ContainerAware`, annotations → attributs). WebFetch la page "Upgrading modules to PrestaShop 9" de devdocs avant d'adapter un module existant.
- **Fiche produit BO** : la nouvelle page est la seule depuis 9.0, l'ancienne n'est plus accessible et ses hooks sont supprimés (`actionAdminProductsController…`, `displayAdminProductsMainStep…`). Champs ajoutés par `actionProductFormBuilderModifier` + `actionAfterUpdateProductFormHandler` ; `displayAdminProductsExtra` toujours supporté mais déconseillé. Caractéristiques : nouvelle structure de données du formulaire en 9.0, à adapter.
- Fiches commande et client BO : mêmes hooks qu'en 8 (`displayAdminOrderMain`, `displayAdminOrderSide`, `displayAdminOrderTabLink` / `TabContent` ; `displayAdminCustomers`, `actionCustomerFormBuilderModifier`) *(à vérifier)*.
- Supprimés aussi en 9.0 : hooks `actionAdminLoginController…` (login BO passé en Symfony ; restent `actionAdminLoginControllerSetMedia`, `displayAdminLogin`). `FrameworkBundleAdminController` déprécié → `PrestaShopAdminController`. `@AdminSecurity` → attribut `#[AdminSecurity]`.
- Debug local : `_PS_MODE_DEV_` à `true` dans `config/defines.inc.php` (ou BO > Paramètres avancés > Performances > Mode debug). Jamais en production.
- Cache : `php bin/console cache:clear` ou `rm -rf var/cache/*`.
