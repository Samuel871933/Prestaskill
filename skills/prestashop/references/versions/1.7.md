# PrestaShop 1.7

Tout ce qui est marqué *(à vérifier)* : grep dans le core ou WebFetch la doc avant de l'utiliser.

PHP 5.4 → 7.4 selon mineure (voir php.md) · Symfony 2.8 (≤ 1.7.3) puis 3.4 · Thème défaut : classic · Thèmes enfants : oui · BO : Smarty + Twig (pages migrées) · Traductions : `$this->trans()` à partir de 1.7.6, sinon `$this->l()` · Doc : https://devdocs.prestashop-project.org/1.7/

- Symfony 3.4 dans le BO, migration progressive : certaines pages sont Symfony (Twig), d'autres legacy. Vérifier dans `src/PrestaShopBundle/Resources/config/routing/` si une page est migrée avant de choisir hook legacy vs hook Grid/Form.
- Hooks Grid et Form (`action<Nom>GridDefinitionModifier`, `action<Nom>FormBuilderModifier`…) : à partir de 1.7.5/1.7.6 selon la page *(à vérifier)*.
- Controllers admin Symfony dans un module (`config/routes.yml`) : 1.7.5+ *(à vérifier)*. `config/services.yml` dans un module : chargé côté admin à partir de 1.7.5 environ *(à vérifier)*.
- Front : `registerStylesheet` / `registerJavascript` dans `hookActionFrontControllerSetMedia`.
- Widgets : `implements WidgetInterface` (`renderWidget`, `getWidgetVariables`), appelables via `{widget name='module'}`.
- Cache : `php bin/console cache:clear` ou `rm -rf var/cache/*` (contient `class_index.php`).

Module multi-versions : voir modules.md § Module compatible multi-versions.
